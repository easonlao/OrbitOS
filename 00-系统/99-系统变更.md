# 系统变更

本页只记录会改变你使用方式的重要变化，不记录内部实现过程。

## 当前版本：v0.2.0（2026-08-12）

### 你需要知道的变化

- **内容去向更明确**：属于项目的内容写入对应项目目录；未确认的内容一律先入收件箱，确认前不会直接进输出区。`07-输出` 已撤销，不再接收新内容。
- **多 Agent 协作可追踪**：任务交接、接手与回交通过协作队列闭环，每个环节都有治理记录。
- **Agent 可注销**：不再使用的 Agent（如 doubao）可走标准注销流程，档案归档、状态留痕。
- **周回顾自动化**：跨周自动归档旧周页并生成新周回顾；异常阻塞会显示在今日页，不再静默失败。

## 最近变化

- 内容路由两条强制规则落地，`07-输出` 按设计消亡（存量已迁移）。
- Agent 注销工作流上线（首个生产用例：doubao 已注销）。
- Engineering 模块启用，代码型项目走 Matt Pocock Skills 工程路径。
- 周回顾支持跨周 rollover，阻塞通过今日页可见。
- 完整历史见项目层 `03-项目/OrbitOS/CHANGELOG.md`。
