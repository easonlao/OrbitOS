# 自动化模块

自动化模块负责那些重复、明确、低风险但容易被忘记的事情，例如系统健康检查、今日页维护和周回顾。首次确认执行器、频率和安全维修边界后，日常、可逆、可验证的维护由 Agent 继续闭环处理；你只在需要判断或授权时介入。

## 它适合什么

- 你希望系统定期检查有没有结构或流程异常。
- 今日页需要定期刷新，避免完全靠人工触发。
- 你希望一周结束时自动得到回顾入口，而不是每次重新想起这件事。

自动化的目标是减少遗漏、留下运行凭证并推动安全维护闭环，不是替你做语义判断或制造更多通知。

## 安全边界

自动任务仍只允许在明确受管范围内工作：可以检查、记录运行凭证、重建今日页受管投影，并由 Agent 继续修复或重试系统层问题。发现问题时会在今日页显示当前状态，不会把旧日志直接当成当前故障。

语义判断、移动/删除/归档用户内容、提升正式知识、外部授权、不可逆操作和重大取舍，都不能因为“自动化”而跳过你的确认。

## 如何开始

```text
我想减少手动维护今日页的频率。请列出适合自动化的任务、各自收益和风险，先不要创建定时任务。
```

确认后再说：

```text
请按我们确认的任务配置自动化，只读检查异常，正常时不要额外通知。
```

时间频率不必预先固定。先确定任务确实有价值，再根据你的节奏决定何时运行。
